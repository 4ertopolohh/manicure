# Работа над проектом

React/Vite/TypeScript strict и SCSS Modules находятся в frontend, Django/Poetry/SQLite — в backend. Django управляет содержанием и расписанием.

Перед изменением записи прочитайте docs/design-decisions.md и backend/studio/booking.py. Проверяйте создание, пересечение интервалов, буфер, отмену и административный перенос через публичные интерфейсы.

Контакты и оригиналы референсов остаются в браузере. Сохраняйте узкий интерфейс makeBooking без аргументов для настоящего имени, телефона и файлов. Сервер генерирует собственную вымышленную идентичность.

Дизайн: без градиентов, надзаголовков и иконок в кнопках. Кнопки, календарь, варианты и прикрепление файлов имеют собственное оформление, плавные состояния и поддержку reduced motion.

Материалы и источники: docs/assets.md. Принципы репозиториев пользователя: docs/reference-blueprint.md. При изменении интерфейса проверяйте ширины 350, 390, 768, 1024, 1280, 1440 и 1920.

Применяйте установленные Matt Pocock skills по задаче. Не переустанавливайте плагин. Сохраняйте задачи и спецификации в GitHub Issues репозитория 4ertopolohh/manicure, когда требуется отдельное отслеживание.

Перед коммитом выполняйте релевантные проверки, смотрите полный diff и исключайте .local, SQLite и зависимости. По указанию владельца коммиты и обычный push идут в main. Историю сохраняйте.
