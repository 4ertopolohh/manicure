# Принципы из проектов TRIAD

Исходники прочитаны через подключение GitHub 8 ноября 2026. Репозитории-источники не изменялись.

- **triad-studio-project**: `frontend/src/App.tsx`, `components/ReactLogo3D/ReactLogo3D.tsx`, `backend/runtime_config/models.py`, package.json, AGENTS.md. Заимствованы отложенная загрузка через lazy/Suspense, skeleton, остановка графики вне экрана, централизованная runtime-конфигурация. Большую сцену Three.js и сложную структуру авторизации сюда не переносим: предметный интерактив реализуется лёгким SVG.
- **conditioners**: `Hero/FanAnimation.tsx`, `Hero768.module.scss`, `components/Modal/Modal.tsx`, `backend/apps/integrations/models.py`, `content/admin.py`, AGENTS.md. Заимствованы уборка наблюдателей, reduced-motion, работа с фокусом и понятные статусы интеграций. PostgreSQL и ограничения по микроэтапам относятся к исходному проекту; здесь по заданию SQLite и законченный локальный сайт.
- **instruments-commerce**: `OrderRequestModal.tsx`, `_mixins.scss`, `catalog/models.py`, `core/admin_mixins.py`. Заимствованы состояния форм, единый модуль запросов, типизация, singleton настроек и русские модели. Реальный сбор контактов и сложный каталог не переносятся.
- **workshop-weight-dev-2**: `WelcomeSection.jsx`, `FeedbackSendButton.jsx`, `_variables.scss`, package.json, AGENTS.md. Заимствованы выразительные композиции и явные loading/disabled состояния. Не переносим дублирующую разметку для разных ширин, устаревшие следы сборки и градиенты.

Frontend и backend независимы. Django — источник услуг, вариантов, галереи, расписания и SEO. Граница модуля записи: доступность, создание и управление по случайному коду. Бронирование сериализуется SQLite write lock до проверки интервалов. И публичная запись, и административный перенос используют одно расписание.

SCSS Modules для компонентов, глобально только базовые токены и общие примитивы. Сетки адаптируются без дублирования контента. SVG-примерка меняет форму, длину и цвет и передаёт выбор в запись.

Реальные контакты и файлы не входят в интерфейс `makeBooking`. Реальные интеграции исключены из демонстрации; локальный адаптер пишет только журнал имитации. Сервер повторно генерирует фиктивную идентичность. Фото и шрифты находятся локально.
