# Тихая форма

Вымышленная студия и один вымышленный мастер. Молочная бумага, пудровый фон конфигуратора, винный акцент и контрастная мужская секция. Cormorant Garamond задаёт редакционную иерархию, Marck Script добавляет рукописную интонацию, Golos Text сохраняет ясность форм. Все шрифты с кириллицей и OFL, размещены локально.

Нет градиентов, декоративной нумерации, надзаголовков, стрелок и иконок в кнопках. Отдельные SVG-иконки применяются только как информационная графика вне кнопок. Анимация: проявление секций через IntersectionObserver, мягкое увеличение фотографий, состояния наведения/нажатия, переход оттенка примерки. Skeleton пульсирует прозрачностью, без градиента. Reduced motion отключает движение.

По уточнению пользователя от 9 ноября 2026 выбор формы ногтей в конфигураторе и попапе использует SVG-силуэты вместо видимых текстовых названий. Это функциональное исключение к запрету декоративных иконок в кнопках. Названия сохранены в aria-label и подсказках при наведении и клавиатурном фокусе; выбранное состояние обозначено рамкой и aria-pressed. Небольшая подпись «Без спешки. Без лишнего. С вниманием к тебе» удалена из hero. Мужская секция раскрывает этапы процедуры и подготовку к первому посещению.

Настройки расписания: несколько непересекающихся периодов на день недели, отдельные выходные и частичные перерывы, шаг старта относительно начала периода, перерыв после услуги, горизонт записи. Процедура вместе с буфером помещается в рабочий период. Увеличение длины добавляет время и стоимость; остальные параметры визуальны и редактируются через админку.

В демоверсии контакты можно ввести, но запрос содержит только случайные значения. Референсы (0–3, JPG/PNG/WebP до 5 МБ) существуют в виде object URL до закрытия окна; имена файлов и байты не отправляются. Сервер сохраняет только количество. Дальнейшее коммерческое подключение загрузок и настоящих контактов потребует отдельной политики обработки данных.

SEO не является сбором персональных данных: title, description, canonical, Open Graph, серверная индексируемая HTML-разметка, robots и sitemap реализованы. Индексация по умолчанию включена по уточнению пользователя; выключается в админке. API и административные маршруты исключены из индексации. Клиентский экран дополняет серверный HTML после загрузки.

Внешние Яндекс Метрика и Яндекс Карты не вызываются. Для тестового режима отображаются согласованные статусы в админке и журнал имитации; после отключения отображаются реальные ограничения конфигурации. Для карты показывается явно иллюстративная локальная схема. Так сохраняется требование не передавать посетительские данные третьим сторонам.
